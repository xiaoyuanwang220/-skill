# 《实习过程记录》模板规范

> 来源：知识库中的《实习过程记录》模板（结构以一般区域地理实习通用模板为例）。
>
> **使用前必做**：首次对话时读一遍知识库里的模板，与本文件逐字段比对。
> - 一致 → 直接按本文件写；
> - 不一致 → **以知识库模板为准**，按实际结构生成 Word，并在交付说明里提示"模板结构与本文件不同，建议同步修订 template-spec.md"。
>
> 生成 Word 时严格还原表格结构与字段顺序，不得增删字段、不得改动标题。

## 二、各字段填写细则

| 字段 | 来源与写法 |
|---|---|
| 项目名称 | `区域综合地理实习`（与指导书一致；用户另有说法从用户） |
| 专业年级 | 用户未提供则留空，交付时提醒补填 |
| 学号 / 姓名 | 用户未提供则留空，**不编造**，交付时提醒补填 |
| 时间 | 录音/行程对应的实际日期（如 `9月18日`）；用户说明与行程表冲突时以用户为准并备注 |
| 地点 | 当天实际考察点。多点位按顺序连写，如 `龙脊梯田—灵渠` |
| 上课老师 | 按带队老师名单填写（名单在首次对话时从指导书/动员 PPT 抽取并向用户确认，确认后固定）。来源优先级：用户指定 > 录音中老师自报姓名 > 留空并在确认环节询问。学生辅助讲解时可在姓名后加注（如 `XX（学生辅助讲解）`） |
| 学习方式 | 按当天实际形式填：`实地考察讲解` / `参观学习` / `小组调研` 等（可组合，如 `实地讲解＋师生问答`） |
| 听课记录 | 见下文"听课记录撰写规范" |
| 观察到的现象和发现的问题 | 见下文对应规范 |

## 三、听课记录撰写规范

1. **口述搭骨架，录音补血肉**：路线、点位顺序、每个点位讲什么，以用户口述为准（当次实际发生的事）；术语原话、数据、师生问答用录音转写补齐。两者不一致时以录音为准，并在交付说明里点出改动。老师讲的内容照写，不替老师"纠偏"课程观点；指导书只用来补背景、校正疑似听错的地名术语（校正处在交付说明里标注）。
2. **按讲解逻辑分段**，不逐字照录：每段一个话题（如"地貌成因""水系特征""人地关系"），保留地名、数据（高程/面积/年代）、专业术语的**原话表述**。
3. **师生问答**：有价值的问答要点以"问：…／答：…"形式简要复现，不展开全文。
4. **联网数据**：确需外部核实的硬数据，只写核实得到两处以上来源支持的部分；单来源或存疑的数字改用定性表述（"海拔约一千米""形成于中生代"），不要写成一个精确到个位的假数字。
5. **篇幅**：与当天内容密度匹配，一般 300–800 字；两条以上录音或两个以上点位合并时按"上午／下午"或点位分段。
6. **口语转书面**：删语气词、重复、口头禅；老师有强调、对比、举例的内容保留。

## 四、"观察到的现象和发现的问题"撰写规范

1. **现象**：来自录音中老师指认的实地观察点、学生所见（录音或照片中体现），如"山体岩层近于水平、节理发育"。
2. **问题**：优先从指导书该站点的**"思考问题"**提炼（如天子山的地貌发育阶段、与喀斯特峰林的差异等）；录音中老师抛出但未展开的问题也列入。
3. **写法**：现象在前、问题在后；问题可带一句作答思路或留白待学生补充，格式如 `问题1：御笔峰处于地貌发育的哪个阶段？主导营力是什么？`。
4. 篇幅一般 100–300 字。

## 五、Word 生成注意事项

- 文档结构：标题 + 表1 + 表2，表格线完整（浅色实线网格），正文小四或五号宋体，标题加粗。
- 单元格内容较长时行距、字号协调，保证单页或两页内完整呈现。
- 文件保存到 `/workspace/outputs/`，命名 `实习过程记录_第X天_地点.docx`。
