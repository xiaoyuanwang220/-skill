# 区域地理实习记录 Skill

一句话：你把当天实习的见闻说清楚、把照片发上来，它按学校模板给你一份可直接提交的《实习过程记录》Word。

它不靠"猜"。你知识库里的老师讲解录音、实习指导书、动员大会 PPT 是它的核对依据；模板是它的排版依据；必要时它还会联网查一下高程、面积、年代这类硬数据。

> **最快上手**：下载 `dist/野外实习记录skill.zip` → 在 ima 里上传 skill → 照第四节的三步开始用。
>
> **仓库结构**：`SKILL.md`（skill 主体逻辑）｜`references/`（模板规范、图片 SOP）｜`dist/`（可直接上传的打包件）｜`README.md`（本文件）

## 零、准备材料清单

先把这些东西凑齐，后面全程省事。

| 材料 | 格式 | 必需性 | 说明 |
|---|---|---|---|
| 《实习过程记录》模板 | docx | **必需** | 学校/学院发的空白模板，决定最终表格结构 |
| 《区域综合地理实习指导书》 | docx / pdf | **必需** | 逐日行程、站点、每站"思考问题"的来源 |
| 老师现场讲解录音 | 音频 | 重要 | 一天可能多条，文件命名 `第X天_地点`（如 `第5天_天子山`）；传进知识库后自动转写 |
| 动员大会 PPT | pptx | 可选 | 项目名称、实习目标、任务与纪律要求的口径 |
| 现场照片 | jpg / png | 可选 | 没有也能出稿，先出带占位符的版本，事后补图 |
| 你的个人信息 | — | 可选 | 学号、姓名、专业年级。不给就留空，它不会编 |

> 录音命名统一成 `第X天_地点`，是整套流程里最省事的一条规矩。一天跑了两个点就传两条（`第7天_龙脊梯田`、`第7天_灵渠`），它会把两条合并成一份当天记录。

## 一、导入 skill

1. 打开 ima，进入 **Copilot** 对话界面。
2. 找到 **skills（技能）** 入口 → **skill 管理** → **上传 skill**。
3. 选择本 skill 的压缩包（`野外实习记录skill.zip`）上传，确认列表中已出现 **区域地理实习记录**。
4. 建议顺手把 skill 开关设为启用，避免每次对话都要手动唤起。

---

## 二、建知识库、放资料

1. 在 ima 里**新建一个知识库**，名字随意（默认按"区域地理实习"建，skill 里也是这么找的；用别的名字，第一次对话时告诉它一声即可）。
2. 把下面四类东西**全部传进这个知识库**：

   - 《实习过程记录》模板（docx）
   - 《区域综合地理实习指导书》（docx / pdf）
   - 动员大会 PPT
   - 往届或本年度的实习记录样例（可选，但有助于它对齐写法）

   另外建一个文件夹/分类放**每天的讲解录音**，命名按 `第X天_地点`。

3. 等知识库处理完（音频转写需要一点时间，看当天录音总时长而定）。**转写没完成就开始写，会写成"没细节的流水账"**，这一点别省。

4. 照片**不用**放进知识库，直接在对话里发就行——知识库里塞照片会拖慢检索，也帮不上写作。

## 三、首次对话：让它自检、建索引

第一次用，对 ima 说这么一段（可直接复制）：

> 我要用「区域地理实习记录」这个 skill 写实习记录。我的知识库叫「区域地理实习」，里面有实习记录模板、实习指导书、动员大会 PPT 和老师讲解录音。
> 请你：① 检索知识库，定位模板和指导书，读出模板的表格结构；② 从指导书里抽出逐日行程、站点、每站的思考问题，整理成一张对照表；③ 告诉我这几份材料是否齐全、缺什么；④ 从指导书和 PPT 里读出项目名称和带队老师姓名，让我确认。

它会：

- 定位知识库和关键文件，拿到后续要反复用的 ID；
- 从**你自己的指导书**里重建"行程—站点—思考问题"索引（不是别人那一届的行程表）；
- 告诉你缺模板还是缺录音，缺录音会提前说明"细节会薄一些"；
- 跟你确认项目名称、专业年级、带队老师名单。

确认完这几项，准备工作就结束了。首次这套动作只做一遍。

## 四、日常使用：三步

### 第 1 步：上传录音到知识库

当天录音传进知识库，文件名 `第X天_地点`。多个点位传多条。

### 第 2 步：发提示词描述今天的见闻 + 发照片

在 Copilot 里把"今天发生了什么"讲清楚。**讲得越具体，成稿质量越高**。可以照着这个结构说：

> 帮我写第 5 天的实习记录。
> 今天全天在张家界武陵源。上午天子山，从贺龙公园一路走到御笔峰观景台，X 老师讲了两件事：一是砂岩峰林的地貌发育阶段，说御笔峰还处在青壮年期；二是这里的岩层近水平、垂直节理发育，是峰林形成的关键。我在观景台看到岩层确实很平，节理把岩体切成一根根石柱。
> 下午袁家界，主要讲《阿凡达》悬浮山的原型问题，老师说电影取景参考的是这里，但成因和喀斯特峰林不一样，具体差别讲了一段，录音里有。
> 我自己的疑问是：为什么同样水平岩层，天子山的峰比袁家界的更细更密？
> 照片 4 张：御笔峰远景、岩层层面特写、袁家界迷魂台全景、和老师讲解现场。
> 需要的话可以联网查一下御笔峰的海拔和岩层年代。

### 第 3 步：让它成文

它会先复述一遍时间线让你确认（内容复杂时），然后核对录音、指导书、必要时联网，最后按模板出 Word。

拿到文档后，重点看三处：

- **基本信息栏**：学号、姓名、专业年级大概率是空的，自己填；
- **交付清单里的"待核项"**：联网没查到、转写可疑的地方，它会点出来；
- **图片位置**：图是否跟着对应段落走。

## 五、提示词怎么写更好用

| 想让它做到 | 提示词里加一句 |
|---|---|
| 补足细节 | "录音里有，你按录音补全" |
| 聚焦某个话题 | "重点写峰林成因，其他一句带过" |
| 加上自己的疑问 | "我提的问题也要写进'发现的问题'" |
| 必须先对稿 | "先给我看时间线和关键信息，我确认后再写" |
| 直接出成品 | "不用确认，直接出稿" |
| 核实数据 | "海拔、面积这类数据可以联网核对，标出来源" |
| 不要联网 | "只用我给的材料和知识库内容，不要联网" |
| 更长/更短 | "听课记录写到 800 字左右" |

## 六、机制说明（省得你踩坑）

- **口述优先，录音核对**：你讲的是骨架，录音用来补术语、数据、师生问答。两边冲突时以录音为准，并会告诉你改了哪里。
- **指导书只补背景**：站点成因、区域背景、每站的"思考问题"来自指导书，它不会拿指导书改老师现场讲的内容。
- **联网是受限的**：只用来核实硬数据、确认专有名称、补一句公开背景；同一个数字要有两处来源才写进正文，只有一处就写"约"或者列进待核清单。联网的内容不会覆盖老师现场讲解，交付时会单独列出"联网核实过的内容"。
- **个人信息不编**：学号、姓名、专业年级缺失就留空，交付时提醒。
- **一天多条录音合并**：按点位或上午/下午合并成一份当天记录，不拆成多个文件。
- **图片两种模式**：动笔前给图 → 直接嵌终稿（模式 B）；稍后补 → 先出占位版 + 图片需求清单（模式 A），照片发来后走补图流程替换。
- **换了一届指导书**：让它重新从指导书抽一遍行程索引，不要沿用旧表——旧表是上一届的路线，会用错站点。

## 七、常见问题

**Q：录音很长，转写要多久？**
A：看总时长，一般十几分钟到一小时的录音处理时间不长。转写没完成就让写，会写成没有细节的流水账，建议先等完成。

**Q：一天跑了四个点，录音好几条，会不会写成四份？**
A：不会，按天合并成一份，内部按点位分段。

**Q：不想传录音行不行？**
A：行。你口述得足够细就能写，只是术语原话、数据、师生问答会薄一些，它会在交付时说明。

**Q：照片是苹果的 HEIC 格式？**
A：会先转成 jpg 再插，原图不动。

**Q：写出来的地名/数据和我知道的不一样？**
A：直接说"这里改成 XXX"。转写听错地名的概率不低，指出来后它会改，并把这类修正记进交付说明。
